# Proyek Analisis Data - E-Commerce Public Dataset

Proyek ini merupakan proyek akhir analisis data menggunakan **E-Commerce Public Dataset** sebagai bagian dari pembelajaran di Dicoding.

Analisis dilakukan untuk memperoleh insight mengenai tren nilai transaksi, kategori produk dengan kontribusi transaksi terbesar, hubungan ketepatan waktu pengiriman dengan skor ulasan pelanggan, serta segmentasi pelanggan menggunakan RFM Analysis.

## Pertanyaan Bisnis

### Pertanyaan 1

Bagaimana tren total nilai transaksi bulanan dan kategori produk dengan kontribusi nilai transaksi terbesar selama periode Januari 2017 hingga Agustus 2018?

### Pertanyaan 2

Bagaimana pengaruh ketepatan waktu pengiriman terhadap skor ulasan pelanggan pada transaksi yang terjadi selama periode Januari 2017 hingga Agustus 2018?

## Tahapan Analisis

Proses analisis data dilakukan melalui beberapa tahapan:

1. Menentukan pertanyaan bisnis menggunakan framework SMART Question.
2. Gathering Data.
3. Assessing Data.
4. Cleaning Data.
5. Exploratory Data Analysis (EDA).
6. Visualization & Explanatory Analysis.
7. RFM Analysis sebagai analisis lanjutan.
8. Menyusun kesimpulan dan rekomendasi.

## RFM Analysis

Analisis lanjutan menggunakan metode **RFM (Recency, Frequency, Monetary)** untuk melakukan segmentasi pelanggan.

- **Recency**: jumlah hari sejak pelanggan terakhir melakukan transaksi.
- **Frequency**: jumlah transaksi yang dilakukan pelanggan.
- **Monetary**: total nilai transaksi yang dikeluarkan pelanggan.

Pelanggan kemudian dikelompokkan ke dalam beberapa segmen berdasarkan skor RFM:

- Best Customers
- Loyal Customers
- Potential Customers
- Regular Customers
- At Risk / Lost Customers

## Dashboard

Dashboard interaktif dibuat menggunakan **Streamlit** untuk menyajikan hasil analisis dalam bentuk visualisasi interaktif.

Dashboard menyediakan beberapa informasi, antara lain:

- Total nilai transaksi
- Total jumlah order
- Rata-rata nilai transaksi per order
- Kategori produk dengan nilai transaksi terbesar
- Tren nilai transaksi bulanan
- 10 kategori produk dengan nilai transaksi terbesar
- Rata-rata skor review berdasarkan ketepatan pengiriman
- Rata-rata skor review berdasarkan tingkat keterlambatan
- Segmentasi pelanggan berdasarkan RFM
- Karakteristik setiap segmen pelanggan

## Menjalankan Dashboard Secara Local

### Prasyarat

Pastikan Python dan pip sudah terinstall pada komputer.

Cek versi Python dengan menjalankan:

```bash
python --version
```

Pada Windows, dapat menggunakan:

```bash
py --version
```

### 1. Clone Repository

Clone repository GitHub:

```bash
git clone https://github.com/nurFattahh/e-commerce-tren-analysis
```

Kemudian masuk ke folder project:

```bash
cd submission
```

### 2. Membuat Virtual Environment

Disarankan menggunakan virtual environment agar dependency project tidak bercampur dengan project Python lainnya.

Pada Windows:

```bash
python -m venv .venv
```

Aktifkan virtual environment:

```bash
.venv\Scripts\activate
```

### 3. Install Dependencies

Install seluruh library yang dibutuhkan menggunakan `requirements.txt`:

```bash
pip install -r requirements.txt
```

### 4. Menjalankan Dashboard

Pastikan terminal berada di folder utama `submission`, kemudian jalankan:

```bash
streamlit run dashboard/dashboard.py
```

Setelah berhasil dijalankan, Streamlit akan memberikan alamat seperti:

```text
Local URL: http://localhost:8501
```

Buka alamat tersebut pada browser untuk mengakses dashboard.

### 5. Menghentikan Dashboard

Untuk menghentikan aplikasi Streamlit, tekan:

```text
Ctrl + C
```

pada terminal.
